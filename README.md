# HWID Инспектор подписок

Веб-инструмент для работы со своими VPN-подписками: генерирует `X-HWID` (как клиент Happ), забирает конфиги с панели, показывает остаток трафика и срок, проверяет живые узлы и экспортирует всё в форматы популярных клиентов.

**Сайт: https://john-smith-two.vercel.app**

---

## Что умеет

| Функция | Описание |
| --- | --- |
| Генерация X-HWID | ANDROID_ID (16 hex) или UUID для iOS-профилей, кнопка «Новый HWID» |
| Свой HWID | Можно вписать существующий ID устройства вручную — с проверкой формата |
| 8 профилей устройств | Pixel, Samsung, Redmi, POCO, OnePlus, iPhone — подставляют нужные `user-agent` и `x-device-model` |
| Разбор подписки | Xray JSON, Clash/Mihomo YAML, base64-список, обычный список ссылок |
| Протоколы | VLESS (в т.ч. Reality), VMess, Trojan, Shadowsocks, Hysteria, Hysteria2, TUIC |
| Проверка узлов | TCP-пинг с сервера: задержка в мс, мёртвые узлы, сортировка по скорости |
| QR-коды | QR для любого конфига и для самой ссылки подписки — сканируешь телефоном |
| Выбор узлов | Галочки + «Оставить только живые», экспорт только выбранных |
| Статистика | Трафик и срок подписки с полосами прогресса, `announce` от панели |
| Экспорт | Ссылки, Base64, Clash/Mihomo YAML, sing-box JSON, Xray JSON, raw-ответ |
| История | Последние 8 ссылок сохраняются локально в браузере |
| Отладка | Готовая `curl`-команда и JSON заголовков, все заголовки ответа панели |

## Как пользоваться

### 1. Вставь ссылку подписки

Поддерживаются любые из этих форматов — лишнее отрежется автоматически:

```
sub.example.com/abcDEF123
https://sub.example.com/abcDEF123
happ://add/aHR0cHM6Ly9zdWIuZXhhbXBsZS5jb20vYWJjREVGMTIz
v2raytun://import/https://sub.example.com/abcDEF123
```

Под полем появится строка `→ https://…` — это адрес, на который реально уйдёт запрос. Если её нет, ссылка разобрана неверно.

### 2. Выбери формат ответа (необязательно)

Список справа от поля:

- **auto (по User-Agent)** — панель сама решает, что отдать. Начинай с этого.
- **/json**, **/v2ray-json** — Xray JSON.
- **/clash**, **/mihomo** — Clash YAML.
- **/sing-box** — sing-box JSON.
- **/v2ray** — base64-список ссылок.

Если узлов не нашлось — попробуй другой пункт: разные панели отдают конфиги по разным путям.

### 3. Настрой устройство и HWID

- Нажми на модель устройства — подставятся `user-agent`, `x-device-os`, `x-ver-os`, `x-device-model`.
- **Новый HWID** — сгенерировать другой ID.
- **свой HWID** — галочка, чтобы вписать ID вручную. Принимаются 16 hex-символов, UUID или произвольный ID из 8–64 символов.

### 4. Забери конфиги

Нажми **«Забрать конфиги с этим X-HWID»** (или Enter в поле ссылки).

Появится сводка: профиль, принят ли HWID, формат, трафик, лимит, дата истечения.

### 5. Работай с узлами

- **Проверить (N)** — TCP-пинг узлов, потом список сам сортируется по задержке. Зелёный < 150 мс, синий < 400 мс, `МЁРТВ` — нет связи.
- **Оставить только живые** — снимает выбор с нерабочих.
- Кнопка QR у строки — код для сканирования телефоном.
- Клик по строке — все параметры узла: SNI, Reality-ключи, fingerprint, flow, path, пароль.

### 6. Экспортируй

Выбери формат, при желании поставь галочку **«только выбранные»**, затем **Копировать всё** или **Скачать**:

| Формат | Файл | Куда |
| --- | --- | --- |
| Ссылки | `configs.txt` | Happ, v2rayTun, Hiddify, Streisand |
| Base64 | `subscription.txt` | как своя подписка |
| Clash / Mihomo | `clash.yaml` | Clash Meta, Mihomo, FlClash |
| sing-box | `sing-box.json` | sing-box, Hiddify |
| Xray JSON | `xray.json` | Xray-core, v2rayN |

## Как это работает

Браузер не может сам отправить `user-agent` и произвольные заголовки на чужой домен, поэтому запрос идёт через серверный роут:

```
Браузер → POST /api/fetch-sub → панель подписки
```

Роут `app/api/fetch-sub/route.ts`:

- пропускает только заголовки `user-agent`, `x-hwid`, `x-device-os`, `x-ver-os`, `x-device-model`;
- разрешает только `http`/`https` и блокирует локальные и приватные адреса (защита от SSRF);
- таймаут 25 секунд;
- разбирает ответ в единый список узлов и возвращает вместе со всеми заголовками панели.

Роут `app/api/ping/route.ts` делает TCP-коннект к узлам (до 80 адресов, по 16 одновременно, таймаут 3.5 с) и отдаёт задержку в миллисекундах. Приватные адреса тоже отсекаются.

Данные подписки нигде не сохраняются — ни базы, ни логов конфигов. Локально в браузере хранится только история ссылок.

## Структура

```
app/
  api/fetch-sub/route.ts   загрузка подписки с HWID-заголовками
  api/ping/route.ts        TCP-пинг узлов
  page.tsx                 страница
  layout.tsx               метаданные, шрифты
lib/
  hwid.ts                  генерация HWID, профили устройств, разбор ссылки
  parse.ts                 парсеры Xray/Clash/base64 → узлы, share-ссылки
  export.ts                генераторы Clash / sing-box / Xray конфигов
  format.ts                байты, склонения, дни
components/
  hwid-console.tsx         основная логика и шаги
  node-list.tsx            список узлов, пинг, выбор, фильтры
  export-panel.tsx         вкладки экспорта
  qr-dialog.tsx            QR-код
  copy-button.tsx          копирование в буфер
```

## Локальный запуск

Нужен Node.js 20+.

```bash
git clone https://github.com/vyacheslavslava22/John-Smith.git
cd John-Smith
npm install
npm run dev
```

Открой http://localhost:3000

Сборка:

```bash
npm run build
npm start
```

Переменные окружения не нужны.

## Важно

Инструмент предназначен только для работы **со своими собственными подписками** — посмотреть свои конфиги, проверить узлы, перенести их в другой клиент. Не используй его с чужими ссылками и для обхода лимитов чужих сервисов.
